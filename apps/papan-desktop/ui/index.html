Pintasan Keyboard (gaya KiCad PCB)

        

          
A
Mode tambah: pilih komponen dari palet, lalu klik papan

          
M / G
Geser komponen terpilih (klik posisi baru)

          
R
Rotasi komponen terpilih +90° (Shift+R = -90°)

          
F
Flip komponen terpilih (F.Cu ↔ B.Cu)

          
Del
Hapus komponen terpilih

          
Esc
Batal alat/operasi, hapus seleksi mode taruh

          
Home
Zoom pas (fit board)

          
+ / -
Zoom in / out

          
←↑↓→
Geser komponen terpilih (snap grid; Shift = 0.1 mm)

          
? / F1
Tampilkan/sembunyikan bantuan pintasan

        

        
Mouse: Klik kiri = pilih/taruh/geser. Tahan tombol tengah = pan. Scroll = zoom. Klik kanan = batal. (Pemetaan KiCad inti; fitur routing/wiring/seleksi kotak menyusul.)
